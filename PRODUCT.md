# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Operations analysts or managers who work with business records.

## Product Purpose

Help users explore a known-schema operations data set and answer questions about orders, delivery risk, fields, and data quality.

## Positioning

Start with an authored, readable table and reveal search, type-aware filters, field discovery, view management, and detail without losing context.

## Operating Context

The prototype uses a synthetic purchase-order fixture. Users inspect current slices, explain search matches, configure fields, and return to the authored default.

## Capabilities and Constraints

The prototype is local-only and uses plain HTML, CSS, and JavaScript. It does not include a backend, authentication, uploads, editing, formulas, pivoting, grouping, or collaboration.

## Evidence on Hand

The confirmed source is the repository brief and intent documentation. The working data is synthetic and must not be treated as production data.

## Product Principles

- Start useful and calm.
- Reveal advanced controls near the need.
- Keep current state and recovery paths visible.
- Match controls and formats to data types.
- Preserve context while inspecting details.

## Accessibility & Inclusion

The brief requires visible keyboard focus, labels for controls, keyboard paths for required actions, sufficient contrast, result-state announcements, and reduced-motion support.
