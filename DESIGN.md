# Design

The prototype is a restrained analytical workbench for operations review.

- Use one system sans-serif stack, warm white paper, graphite text, pale neutral panels, and one blue action accent.
- Keep the authored default sparse: title, state summary, compact commands, and six visible table fields.
- Use thin rules, compact density, square-corner controls, and status treatments with text plus semantic color.
- Reveal complexity through the field rail, removable state chips, and a right-side record inspector.
- Keep table headers sticky, numbers right aligned, descriptions clamped, and horizontal overflow explicit at narrow widths.
- Make focus, saved/modified state, empty state, malformed dates, nulls, and hidden-field search matches visible.
- Respect reduced motion and keep all required actions available to keyboard users.
